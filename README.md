# 미대이음 프로토타입

미대이음은 미대 입시생이 지역과 전형에 맞는 미술학원 정보를 찾고, 익명 리뷰를 등록할 수 있도록 돕는 발표용 웹사이트 프로토타입입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 주요 페이지

- `/` 메인 페이지
- `/academies` 학원 찾기
- `/academies/:id` 학원 상세
- `/review/new` 리뷰 등록
- `/about` 미대이음이란?
- `/login` 로그인

## 현재 구현 상태

- 학원 데이터는 `src/data/academies.ts`의 초기 후보 데이터를 사용합니다.
- 리뷰 등록 데이터는 브라우저 `localStorage`에 저장됩니다.
- 등록된 리뷰는 운영자 확인 전 상태인 `pending`으로 저장됩니다.
- 학원 상세 페이지의 위치 확인은 지도 API가 아니라 네이버 지도 검색 링크로 연결합니다.
- 현재 로그인과 관리자 검수 화면은 학교 프로젝트용 시연 기능입니다. 실제 운영에서는 별도 인증 시스템이 필요합니다.

## 구글폼 리뷰 반영 원칙

- 사용자가 작성한 후기 원문은 리뷰 데이터의 핵심 정보이므로 임의로 요약하거나 말투를 바꾸지 않습니다.
- 개인정보나 비방성 표현이 포함된 경우에도 원문은 `detailOriginal`에 별도 보존하고, 공개용 수정본은 `detailPublic` 필드에 따로 관리합니다.
- 구글폼에는 한 줄 후기 문항이 없으므로 `summary`를 자동 생성하지 않습니다.
- 리뷰 카드 미리보기는 데이터를 수정하지 않고 UI에서 원문 앞부분을 잘라 표시합니다.

## 주요 대비 대학 리스트

- 대학 리스트는 리뷰 등록과 학원 찾기에서 주요 대비 대학을 선택하기 위한 초기 데이터입니다.
- 학과 개편과 모집 방식은 매년 바뀔 수 있으므로 실제 입시 정보는 각 대학 모집요강으로 확인해야 합니다.
- 미대이음의 주요 대비 대학 정보는 리뷰 기반 참고 정보이며, 학원의 공식 합격률이나 성과를 의미하지 않습니다.

## 주요 대비 대학 데이터 운영 방식

- 초기 152개 학원 중 공개 자료로 대학명이 확인된 학원만 `schoolTags`를 채웠습니다.
- 근거가 부족한 학원은 빈 배열로 유지합니다.
- 리뷰가 쌓이면 `reviewSchoolTags` 집계를 우선 반영합니다.
- 주요 대비 대학은 학원의 공식 합격률이나 성과를 의미하지 않습니다.
- 실제 입시 정보와 모집 요강은 각 대학 공식 모집요강으로 확인해야 합니다.

## 지도 연결 방식

- 현재 미대이음은 지도 API를 직접 사용하지 않고, 네이버 지도 검색 링크로 위치를 연결합니다.
- API 키가 필요 없고 정적 배포 환경에서 바로 사용할 수 있습니다.
- 좌표가 없는 학원은 외부 지도 링크로 fallback합니다.
- 학원 사진이나 지도 이미지를 캡처해서 사이트에 저장하지 않습니다.

## 추가 학원 후보 데이터

- 추가 학원 100개는 공개 출처에서 주소가 확인된 1차 후보 데이터입니다.
- 실제 서비스 반영 전 지도/공식 채널 검수가 필요합니다.
- `verifiedStatus`가 `확인 필요`인 항목은 운영자가 검수해야 합니다.
- 홈페이지, 인스타그램, 블로그는 추후 overlay 데이터로 보강할 수 있습니다.

## 서버 없는 검수 반영 방식

1. 운영자 페이지에서 구글폼 리뷰를 검수합니다.
2. 학원 매칭, 대학명 정리, 공개/보류/제외 상태를 저장합니다.
3. `검수 결과 내보내기` 버튼을 눌러 `midaeium_review_admin_export.ts` 파일을 받습니다.
4. 해당 파일 내용을 `src/data/adminReviewedData.ts`에 반영합니다.
5. 다시 배포하면 모든 사용자에게 검수 결과가 반영됩니다.
6. 이 방식은 서버가 없는 프로토타입용이며, 실제 장기 운영 시에는 Supabase 같은 DB로 전환해야 합니다.
